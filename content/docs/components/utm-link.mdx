## Installation

```bash
npx shadcn@latest add @vinkas-ui/utm-link
```
<small>Make sure you already have the @vinkas-ui registry added to your components.json file. Read the <a href="/docs/installation">installation guide</a> for more information.</small>

## API Reference
See the [Link](https://nextjs.org/docs/app/api-reference/components/link) documentation of nextjs for more information. `Link` is used as the base component for `UTMLink`.
