## Installation

```bash
npx shadcn@latest add @vinkas-ui/composer
```
<small>
Make sure you already have the @vinkas-ui registry added to your components.json file. Read the <a href="/docs/installation">installation guide</a> for more information.
Also, you should have installed the [Typeset](https://ui.shadcn.com/docs/typeset) from shadcn/ui.
</small>

### Properties

| Property | Type | Required | Description | Default |
|----------|------|----------|-------------|---------|
| text | string | Yes | The markdown text. | - |
| className | string | No | The className to be applied to the component. | - |
