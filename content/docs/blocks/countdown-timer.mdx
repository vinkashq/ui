## Installation

```bash
npx shadcn@latest add @vinkas-ui/countdown-timer
```
<small>Make sure you already have the @vinkas-ui registry added to your components.json file. Read the <a href="/docs/installation">installation guide</a> for more information.</small>

### Properties

| Property | Type | Required | Description | Default |
|----------|------|----------|-------------|---------|
| date | Date | Yes | The date to countdown to. | - |
